# SP001 — İskelet ve model erişimi

Feature: [SP001](../features/SP001.md) · Repo: api-debug-agent

## Adımlar

1. Paketler: `analysis/`, `sqllog/`, `schema/`, `llm/`, `telemetry/`, `web/`.
2. Spring AI Anthropic konfigürasyonu, tek `AnthropicChatModel` bean'i.
3. `llm/LlmClient` — modele giden **tek** giriş noktası. Yalnızca F14'teki
   zenginleştirme katmanı çağırır; tespit hiçbir yerde modele gitmez.
   ```java
   LlmResult ask(String promptName, Map<String,Object> vars);
   ```
   `ChatModel`'i başka hiçbir sınıf çağırmaz.
4. `application.yml`:
   ```yaml
   target:
     base-url: http://localhost:8080
   llm:
     enabled: true          # false → model katmanı devre dışı, analiz yine çalışır
     model: claude-sonnet-5
     max-tokens: 3000
   analysis:
     n-plus-one:
       min-repeat: 5
   ```
5. `llm/PromptLoader` — prompt'ları `src/main/resources/prompts/` altından okur.
   Java string literal'ı içine prompt yazma.
6. `LlmResult` içinde ham metin dursun. Token sayımı, maliyet hesabı, çağrı
   kaydı **yok** — telemetri kapsam dışı.
7. JSON parse yardımcısı: model bazen ` ```json ` bloğu içinde döner, temizle.
   Parse edilemezse anlaşılır hata fırlat, sessizce boş dönme.

## Kararlar

- Paket `com.furkan.apidebugagent` olarak kaldı; `.claude/CLAUDE.md`'deki
  `com.adesso.debugagent` referansı bu isme uyacak şekilde düzeltildi.
- `telemetry/` paketi oluşturulmadı — dokümanın kendi "Tuzaklar" bölümü
  telemetriyi kapsam dışı sayıyor.
- `analysis/`, `sqllog/`, `schema/`, `web/` paketleri henüz açılmadı; git boş
  dizin tutmuyor ve içi boş `package-info.java` gereksiz olurdu. Bu paketler
  kendi ilk gerçek sınıflarıyla birlikte ilerideki task'larda açılacak.
- `target.base-url` ve `analysis.n-plus-one.min-repeat` `application.yaml`'a
  literal olarak eklendi ama bunları okuyan `sqllog`/`analysis` kodu henüz
  yok, bu yüzden şimdilik `@ConfigurationProperties` sınıfları açılmadı.
- JSON parse yardımcısı (`JsonResponseParser`) `LlmResult`'tan ayrı, bağımsız
  test edilebilir bir sınıf; `ask()` içinde otomatik çağrılmıyor — doğrulama
  adımı "çağrı yap" ve "JSON'u parse et"i iki ayrı adım olarak tarif ediyor.
- Prompt dosya uzantısı `.st` seçildi (Spring AI'ın `PromptTemplate`'i
  varsayılan olarak StringTemplate/ST4 kullanıyor, `{var}` delimiter'ları).
- `LlmClient`, `AnthropicChatOptions`'ı (generic `ChatOptions` değil) inşa
  ediyor — `AnthropicChatModel.createRequest()` içinde `instanceof
  AnthropicChatOptions` kontrolü var; generic builder kullanılsaydı model adı
  sessizce yok sayılırdı. Bu, `LlmClient`'in provider'a sızdığı tek nokta.
- `ChatModel` `ObjectProvider<ChatModel>` ile enjekte ediliyor; `llm.enabled=false`
  iken context'in API key olmadan da sorunsuz açılmasını garanti ediyor.
- Jackson `ObjectMapper` Spring bean'i olarak mevcut değil (bu Boot 4.1
  kurulumunda `spring-boot-starter-webmvc` Jackson autoconfig'ini
  getirmiyor); `JsonResponseParser` kendi `ObjectMapper`'ını oluşturuyor,
  yeni bağımlılık eklenmedi.
- `PromptTemplate`'in render'ı şablon içindeki `\n`'i platform satır
  ayracına çeviriyor (Windows'ta `\r\n`); testler bunu `System.lineSeparator()`
  ile karşılıyor.
