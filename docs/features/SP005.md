# SP005 — Bulgu zenginleştirme (model)

Durum: ✅
Task: [SP005](../tasks/SP005.md)

## Amaç

Deterministik bulgunun üstüne insan diliyle açıklama ve düzeltme önerisi
eklemek. Model **yalnızca** bu katmanda çalışır.

## Sınır

Tespit F13'te bitiyor. Model:

- bulgu **ekleyemez**
- bulgu **çıkaramaz** ya da eleyemez
- tekrar sayısı, bind sayısı, güven düzeyi gibi **ölçülmüş hiçbir değeri
  değiştiremez**

Yalnızca iki alan üretir: açıklama metni ve düzeltme önerisi.

## İsterler

- **Rapor model olmadan da eksiksiz olmalı.** Model katmanı kapatıldığında
  bulgular, sayılar ve güven düzeyleri değişmeden görünmeli.
- Model çağrısı başarısız olursa rapor yine dönmeli; açıklama alanları boş
  kalmalı, analiz hataya düşmemeli.
- Model her bulgu için: bu ne anlama geliyor, hangi ilişki yüzünden oluşuyor,
  nasıl düzeltilir.
- Düzeltme önerisi somut olmalı ve beklenen sonucu sayıyla ifade etmeli.
- Model yalnızca kendisine verilen bulgu alanları üzerinden konuşmalı; olmayan
  tablo veya kolon adı üretmemeli.
- Modele ham log gitmemeli.
- Bulgu yoksa model hiç çağrılmamalı.
- Model katmanı config'ten kapatılabilmeli.

## Kabul kriterleri

- [x] Model kapalıyken rapor eksiksiz üretiliyor
- [x] Model çağrısı hata verse de rapor dönüyor
- [x] Modelin ürettiği metin ölçülmüş değerlerin üzerine yazmıyor
- [x] Eşleşmeyen bulgu anahtarları yok sayılıyor
- [x] Bulgu yokken model çağrılmıyor
- [x] Model talimatları kod içinde gömülü değil
