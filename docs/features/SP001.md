# F10 — İskelet ve model erişimi

Durum: ⬜
Task: [T001_0](../tasks/T001_0.md)

## Amaç

Agent projesinin taşıyıcı yapısı ve dil modeline erişim katmanı.

## İsterler

- Modele giden tek bir yol olmalı; çağrılar koda dağılmamalı.
- Model katmanı **kapatılabilir** olmalı; kapalıyken analiz eksiksiz çalışmalı.
  Model tespit sürecinin parçası değil, üstüne eklenen bir katman.
- Kullanılacak model kod değişikliği olmadan değiştirilebilmeli.
- API anahtarı koda gömülmemeli.
- Modelden yapılandırılmış çıktı alınabilmeli; serbest metin ayrıştırmaya
  kalkışılmamalı.
- Hedef servisin adresi config'ten gelmeli.

## Kabul kriterleri

- [ ] Model çağrıları tek bir sınıftan geçiyor
- [ ] Model adı ve anahtar config'ten geliyor
- [ ] Model JSON dönüyor, parse edilebiliyor
- [ ] Bozuk JSON geldiğinde anlaşılır hata veriyor
- [ ] Model kapalıyken uygulama sorunsuz çalışıyor
