# SP001 — İskelet ve model erişimi

Durum: ✅
Task: [T001_0](../tasks/T001_0.md) · [T001_1](../tasks/T001_1.md)

## Amaç

Agent projesinin taşıyıcı yapısı ve dil modeline erişim katmanı.

## İsterler

- Modele giden tek bir yol olmalı; çağrılar koda dağılmamalı.
- Model katmanı **kapatılabilir** olmalı; kapalıyken analiz eksiksiz çalışmalı.
  Model tespit sürecinin parçası değil, üstüne eklenen bir katman.
- Kullanılacak model kod değişikliği olmadan değiştirilebilmeli.
- Farklı sağlayıcılar (Anthropic, OpenRouter) aynı arayüzün arkasında
  durmalı; aktif sağlayıcı config'ten seçilmeli. Yeni bir sağlayıcı eklemek
  mevcut sınıfları değiştirmemeli.
- API anahtarı koda gömülmemeli.
- Modelden yapılandırılmış çıktı alınabilmeli; serbest metin ayrıştırmaya
  kalkışılmamalı.
- Hedef servisin adresi config'ten gelmeli.

## Kabul kriterleri

- [x] Model çağrıları tek bir sınıftan geçiyor
- [x] Model adı ve anahtar config'ten geliyor
- [x] Model JSON dönüyor, parse edilebiliyor
- [x] Bozuk JSON geldiğinde anlaşılır hata veriyor
- [x] Model kapalıyken uygulama sorunsuz çalışıyor
- [x] Çağıran taraf tek bir sınıf (`ChatClientLlmClient`) görüyor, sağlayıcıyı
      bilmiyor
- [x] Aktif sağlayıcı `llm.provider` ile config'ten seçiliyor
- [x] Yeni sağlayıcı eklemek mevcut sınıflara dokunmayı gerektirmiyor
