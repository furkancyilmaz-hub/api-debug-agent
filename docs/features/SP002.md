# SP002 — Şema metadata (foreign key) cache

Durum: ✅
Task: [T002_0](../tasks/T002_0.md)

## Amaç

Parent-child ilişkisini tahminle değil, veritabanının kendi tanımıyla bulmak.

## İsterler

- Foreign key ilişkileri uygulama ayağa kalkarken **bir kez** alınmalı ve
  bellekte tutulmalı; her analizde tekrar çekilmemeli.
- Bilgi hedef servisten HTTP üzerinden alınmalı; agent hedefin veritabanına
  bağlanmamalı.
- "Şu tablonun şu kolonu hangi tabloya işaret ediyor" sorusu hızlı
  cevaplanabilmeli — algoritmanın sıcak yolunda kullanılacak.
- Hedef ayakta değilken uygulama açılışı patlamamalı; metadata sonradan
  tazelenebilmeli.

## Kabul kriterleri

- [x] FK listesi açılışta bir kez çekiliyor
- [x] `(tablo, kolon)` → parent tablo araması sabit zamanlı
- [x] Hedef kapalıyken uygulama açılıyor, analiz anlaşılır hata veriyor
- [x] Metadata elle tazelenebiliyor
