# SP003 — SQL ayrıştırma ve normalize

Durum: ✅
Tasklar:
[T003_0](../tasks/T003_0.md) log toplama ·
[T003_1](../tasks/T003_1.md) parse ve normalize

## Amaç

Ham log satırlarını, algoritmanın üzerinde çalışabileceği yapılandırılmış
sorgu kayıtlarına çevirmek.

## İsterler

- Kullanıcının seçtiği zaman aralığındaki loglar alınabilmeli.
- Yalnızca SELECT sorguları dikkate alınmalı.
- Her sorgu için şunlar güvenilir biçimde çıkarılmalı: hangi tablodan okuduğu,
  WHERE'de hangi kolon üzerinde parametreli eşitlik olduğu.
- Bu çıkarım **string işlemleriyle değil**, gerçek bir SQL ayrıştırmasıyla
  yapılmalı — alias'lar, join'ler ve farklı yazım biçimleri string yaklaşımını
  kırar.
- SQL'ler karşılaştırılabilir bir şablona indirgenmeli; aynı statement'ın farklı
  koşuları aynı şablona düşmeli.
- Her sorgunun bind ettiği parametre değerleri sorguyla ilişkilendirilebilmeli.
- Sorgular bir istek içinde çalıştırılma sırasına göre dizilebilmeli.

## Kabul kriterleri

- [x] Zaman aralığıyla log çekiliyor
- [x] SELECT dışı satırlar eleniyor
- [x] Tablo adı ve FK kolonu alias'lı sorgularda da doğru çıkıyor
- [x] Aynı statement'ın 200 koşusu tek şablonda toplanıyor
- [x] Bind değerleri doğru sorguya bağlanıyor
- [x] Sıralama deterministik
